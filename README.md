## 📖 Overview

**DGA Detection & Threat Explorer** is a teaching and research service for screening domain names generated by **Domain Generation Algorithms (DGAs)**, using only the domain string.

It does this by:

- 🔹 **Training a 5-slot ensemble**: Logistic Regression, Random Forest, XGBoost, a character-level LSTM, and a character-level 1D-CNN
- 🔹 **Serving it over FastAPI**, with a Swagger UI at `/docs`
- 🔹 **Shipping a dependency-free browser UI** (no npm, no build step) for detection, batch scoring, 3D exploration, a lab, an evasion loop, and a Human-vs-AI game

> [!NOTE]
> Everything runs locally and is reproducible: deterministic synthetic training data is built in, and the full real-data pipeline is one command away.

## ✨ Features

| Feature | What it does |
| ------- | ------------ |
| 🔎 **Detect** | Scores one domain and returns verdict, probability, per-slot scores, features, family, and a plain-language explanation |
| 📦 **Batch** | Scores up to 500 domains at once with summary counts |
| 🧊 **3D** | Teaching view of domains as 3D character-projection coordinates |
| 🧪 **DGA Lab** | Generates deterministic LCG / MD5 / dictionary samples and scores them; tests fixed string variants for robustness |
| 🧠 **Explain** | Exact Logistic Regression logit attributions for any domain |
| 🔬 **Experiments** | Family-held-out evaluation to test generalization to unseen DGA families |
| 🧬 **Mutation** | Bounded mutations under length, randomness, digit, vowel, and word controls |
| 🎯 **Typosquat check** | Flags non-exact brand lookalikes such as `amozon` and `paypa1` |
| 🖥️ **Simulation** | Local DGA-vs-benign detection simulation |
| ⚔️ **Evasion loop** | Attacker-vs-defender loop that mutates domains to fool all five slots, with a detection curve and an optional lab refit |
| 🎮 **Human vs AI** | Balanced rounds that compare human accuracy against the same ensemble |
| 📊 **Results** | Holdout metrics and per-family breakdown |

> [!TIP]
> The UI tabs mirror the API. Press keys `1`–`9` to switch tabs.

## 🧰 Tech Stack

| Layer | Technology |
| ----- | ---------- |
| **Language** | Python 3.10+ (Docker image uses 3.11-slim) |
| **API** | FastAPI, Uvicorn |
| **Classical ML** | scikit-learn (TF-IDF, Logistic Regression, Random Forest), XGBoost |
| **Deep learning** | Keras character-level LSTM and 1D-CNN |
| **Domain parsing** | `tldextract` (offline) |
| **Frontend** | Static ES-module UI, no npm or build step |
| **Testing** | pytest |
| **DevOps** | Docker, Docker Compose, Makefile |

## 🧠 Model Suite

| Slot | Input | Role |
| ---- | ----- | ---- |
| `LR` | char 2–4-gram TF-IDF + 10 lexical features | Explainable baseline; logit attributions; lab refit head |
| `RF` | same sparse matrix | Strong classical reference; fast CPU inference |
| `XGB` | same sparse matrix | Best random-holdout F1 in `report/report.md`; hard-to-evade gradient signal |
| `LSTM` | char sequence (SLD, ≤63) | Order-sensitive view that treats random-looking strings differently from n-grams |
| `CNN` | char sequence (SLD, ≤63) | Local-motif view (runs, digit clusters) that complements the LSTM |

The displayed **DGA score is the mean of the available slot probabilities**.

Diversity is the point: the evasion loop must fool *all* slots at once, and the Human-vs-AI game compares human accuracy against that same ensemble. Keeping all five is deliberate. Dropping to classical-only would make evasion trivially easy and the game less informative.

## 🧱 Architecture

```mermaid
flowchart TD
    A["🌐 Domain string"] --> B["Normalize + split<br/>tldextract, offline"]
    B --> C["FeatureUnion<br/>char TF-IDF 2–4g 12k + 10 handcrafted features, scaled"]
    B --> D["Char-ID sequence<br/>SLD, max 63"]
    C --> E["LR"]
    C --> F["RF"]
    C --> G["XGB"]
    D --> H["LSTM"]
    D --> I["1D-CNN"]
    E & F & G & H & I --> J["Mean probability"]
    J --> K["Verdict · Risk · Family · Explanation"]
    E -.-> L["Exact LR logit attributions"]
```

**Service layout:** `app/` (FastAPI + static ES-module UI) sits over `src/` (data, features, inference, training, evasion, game, simulation).

Training writes `models/model_bundle.joblib` plus `lstm.keras` and `cnn.keras`. The API loads the bundle if present, otherwise it uses the synthetic fallback. Stale Keras bundles are skipped slot by slot, with a `load_warnings` field, instead of crashing the service.

## 🚀 Quick Start

### Prerequisites

- Python **3.10+** and `pip`
- No npm or frontend build needed

### Installation

**Windows (PowerShell)**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**Linux / macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Then open:

- 🖥️ **App:** <http://127.0.0.1:8000>
- 📚 **Swagger UI:** <http://127.0.0.1:8000/docs>

> `make install run` and `make test` are equivalent shortcuts.

### 🏋️ Full 5-slot training (real data)

```bash
python -m pip install -r requirements.txt -r requirements-optional-ml.txt
python -m src.train --dga-csv "C:\path\dataset_all.csv" --tranco-csv "C:\path\tranco.csv" --max-per-class 20000 --epochs 5
```

**Inputs**

- DGA CSV with `domain,class` columns
- Optional headerless Tranco `rank,domain` CSV for presumed-benign augmentation

**What the loader does:** normalizes domains, drops cross-label SLD collisions, dedups by SLD, marks multi-family DGA SLDs as `ambiguous`, then stratified-samples per family.

**Outputs:** metrics and `per_family.csv` land in `results/`, and the model bundle lands in `models/`. **Restart the API after training.**

**Synthetic fallback** (no data needed, seed 42):

```bash
python -m src.train
```

## 🐳 Docker

The image is intentionally **slim**: Python 3.11-slim, base requirements only, and no model files baked in. It boots on the synthetic LR + RF fallback in seconds with about 200–400 MB RAM. No GPU and no TensorFlow download.

```bash
docker build -t dga-threat-explorer:slim .
docker run --rm -p 8000:8000 dga-threat-explorer:slim
```

Or with Compose:

```bash
docker compose up --build
```

<details>
<summary><b>Running the full ensemble inside Docker</b></summary>

Install the ML bundle at build or run time and retrain with your CSVs mounted, or train on the host and mount `./models` read-only (Compose already mounts it).

If a mounted bundle was built with an older Keras, its sequence slots are skipped with a warning instead of crashing.

</details>

## 🔌 API Reference

| Method | Path | Purpose |
| ------ | ---- | ------- |
| `GET` | `/api/health` | Status, `models_loaded`, dataset stats, `load_warnings` |
| `POST` | `/api/predict` | One domain → verdict, probability, slots, features, family, explanation |
| `POST` | `/api/predict/batch` | ≤500 domains + summary counts |
| `POST` | `/api/explain` | Exact LR logit attributions (not ensemble) |
| `POST` | `/api/generate` | Deterministic LCG / MD5 / dictionary samples, scored |
| `POST` | `/api/robustness` | Fixed string variants (append-word, hyphen, lengthen) |
| `POST` | `/api/typosquat` | Lookalike check: exact brand hit or ≤2 edits from a known brand |
| `POST` | `/api/adversarial` | Bounded mutation under length / randomness / digit / vowel / word controls |
| `POST` | `/api/evasion/loop` | **#1** Attacker-vs-defender: rounds 0–N detection curve + evasive samples |
| `POST` | `/api/evasion/retrain` | **#1** Lab refit on evasives (before/after, bundle untouched) |
| `GET` | `/api/game/sample?count=8&seed=42` | **#3** Balanced Human-vs-AI round with truth + model answers |
| `POST` | `/api/simulate` | Local DGA-vs-benign detection simulation |
| `POST` | `/api/experiments/unseen` | Family-held-out evaluation (default LR) |
| `GET` | `/api/points` | 3D teaching coordinates, or `[]` |
| `GET` | `/api/results` | Holdout metrics + message |
| `GET` | `/api/export?fmt=csv\|json` | In-memory scan history download |

## 🔬 Methodology

| Aspect | Approach |
| ------ | -------- |
| **Labels** | Binary (benign 0 / DGA 1) plus a family string. Tranco is treated as *presumed* benign. |
| **Split** | Stratified random holdout (25%), SLD-deduped so no label crosses the split. This is *not* a time-based or family-disjoint test. See `/api/experiments/unseen` and the family-held-out CSV for generalization evidence. |
| **Features** | Second-level-label TF-IDF plus length, entropy, vowel/consonant/digit ratios, hyphens, longest consonant run, unique ratio, dictionary coverage, and TLD length. The vectorizer is fit on train only; deep models use fixed 63-char IDs. |
| **Calibration** | None. Probabilities are uncalibrated ranking scores. |
| **Evasion lab** | Bounded deterministic mutations (`src/adversarial.py`) searched in `src/evasion.py`. The refit trains a fresh LR head on the *frozen* vectorizer and never overwrites the saved bundle. |
| **Game** | `src/game.py` deals balanced legit/DGA rounds from local pools plus deterministic generators. Labels are known by construction. |
| **Lookalike override** | A non-exact brand lookalike (`amozon`, `paypa1`) forces verdict DGA / risk HIGH (displayed score floored at 0.85, raw DGA score kept in `warnings`). An exact brand-name match (`amazon`) keeps the model verdict. |

## 📁 Repository Layout

```
app/                  FastAPI (main.py, schemas.py, services.py) + static UI
app/static/js/        router, api, pages + detect/batch/evasion/game/simulation/…
src/                  data, features, dga_internals, inference, character_models,
                      adversarial, evasion (#1), game (#3), simulation, experiments, train
tests/                API + leakage/bundle round-trip tests
data/{raw,processed}/ local datasets (git-kept dirs, ignored contents)
models/               model_bundle.joblib + *.keras (local only, ignored)
results/              metrics.csv, per_family.csv, points3d.json (local only, ignored)
report/               full write-up + real-data metrics table
notebooks/            2-cell Colab pointer (uses src.train)
Dockerfile            slim CPU runtime (synthetic fallback, no TF/XGB)
docker-compose.yml    local run with optional model/result mounts
Makefile              install / run / train / test / docker shortcuts
```
